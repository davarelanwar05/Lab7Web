# Lab7Web_PHP — Praktikum 7: Pemrograman Server-Side dengan PHP

## Tujuan
Memahami PHP server-side: variabel, percabangan, perulangan, function, form GET/POST, serta validasi dan sanitasi input.

## Perangkat
Laptop/PC, browser, Visual Studio Code, PHP, XAMPP/Laragon.

## Cara Menjalankan
1. Salin folder `Lab7Web_PHP` ke `htdocs` (XAMPP) atau `www` (Laragon).
2. Jalankan Apache dari XAMPP/Laragon.
3. Buka `http://localhost/Lab7Web_PHP/` di browser (jangan klik ganda file PHP).

## Struktur File
| File | Isi |
|---|---|
| index.php | Latihan 1 + daftar menu |
| latihan2.php | Variabel, operator, percabangan |
| latihan3.php | Perulangan dan array |
| latihan4.php | Function |
| latihan5_cari.php | Form GET |
| latihan6.php | Form POST |
| latihan7.php | Pengolahan data sederhana |
| mini_project.php | Formulir Data Mahasiswa |
